## 🛠️ 快速部署

### 1. 环境准备
系统需运行在 Python 3.6+ (本项目已兼容 Python 3.6.8)。

### 2. 安装依赖
```bash
pip install -r requirements.txt
```

### 3. 启动服务
```bash
python app_v2.py
```
服务默认启动在 `http://localhost:5000`。

### 4. 访问前端
直接在浏览器打开 `index.html`，或者配置 Nginx 代理后端端口。

## 📄 核心功能说明

### 1. 多模型智能路由
- **DeepSeek V3**: 通用最强，适合创意写作。
- **Qwen3.6-Plus**: 逻辑推理强，适合结构化内容。
- **容灾机制**: Token Plan 403 时自动降级至 GLM-5。

### 2. 医药准入专家模式
- 选择场景 `expert_access` 后，系统自动加载集采/医保策略模板。
- 结合 AI 推理，输出包含背景分析、竞争策略、准入路径的专业报告。

### 3. 支付与商业化 (待接入)
- 当前版本包含完整的支付 API 接口 (`/api/payment/*`)。
- **现状**: 模拟扣费流程，未对接微信/支付宝真实网关。
- **下一步**: 需申请企业商户号 (MCH ID) 及 API 证书。

## 🔧 配置说明
- 数据库默认使用 `wenyan.db` (SQLite)。
- API Key 配置请修改 `app_v2.py` 中的环境变量或使用 `.env` 文件。
