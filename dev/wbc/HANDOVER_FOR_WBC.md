## 🎯 你需要审查的核心文件

### 1. 认证与限流 (`auth.py`, `rate_limiter.py`)
- [ ] 检查 JWT 实现是否安全
- [ ] 检查密码哈希（bcrypt）是否正确
- [ ] 检查限流算法（滑动窗口）是否有效
- [ ] 检查是否有 SQL 注入风险

### 2. 支付系统 (`payment.py`)
- [ ] 检查微信/支付宝回调签名验证
- [ ] 检查订单状态机是否完整
- [ ] 检查是否有重放攻击风险
- [ ] 检查金额计算是否精确（使用 Decimal）

### 3. 管理后台 (`admin.html`, `app.py` admin routes)
- [ ] 检查权限控制是否严格
- [ ] 检查敏感操作是否有审计日志
- [ ] 检查 CSRF 防护

### 4. 测试覆盖 (`test_*.py`)
- [ ] 运行所有测试：`pytest -v`
- [ ] 检查边界条件测试
- [ ] 检查安全测试用例

## 🚀 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行测试
pytest -v --tb=short

# 3. 启动服务（本地测试）
export FLASK_ENV=development
python app_v2.py

# 4. 访问管理后台
# http://localhost:5000/admin
```
